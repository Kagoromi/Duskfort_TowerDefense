# Duskfort — Tower Defense Game

A 3D isometric Tower Defense game developed in Unity 6 using C# and Object-Oriented Programming principles.

## About

Duskfort challenges players to defend their base from endless enemy waves by placing and upgrading towers. Built as a university coursework project demonstrating OOP concepts in game development.

## Features

- Fixed isometric camera perspective
- 5 enemy types: Invader, Drone, Cruiser, Armored, Commander
- 3 tower types: Rapid, Heavy, Slow (with slow effect)
- Tower upgrade system up to level 3
- Random gold drops from enemies
- Infinite waves with increasing difficulty
- Particle effect on enemy death
- Sound effects and background music
- Top-5 leaderboard saved via PlayerPrefs
- Full session statistics exported to stats.txt

## Tech Stack

- Engine: Unity 6
- Language: C#
- IDE: Visual Studio
- OOP Concepts: Inheritance, Polymorphism, Encapsulation
- Design Pattern: Singleton

## Assets Used

- 3D Models: Kenney Tower Defense Kit (kenney.nl)
- Music & SFX: freetouse.com

## How to Run

1. Clone the repository
2. Open in Unity 6
3. Open Assets/Scenes/MainMenu scene
4. Press Play
